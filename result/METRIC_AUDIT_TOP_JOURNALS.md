# 面向 JEM/JCP 类论文的指标审计与后续分析建议

## 已达到的基础要求

- **主终点清晰。** 主终点统一称为 `cost`，定义为 `cost = -mean_monthly_reward`。
- **深度强化学习重复性。** 输出全部 10 个训练种子、配对点、置信区间和统计敏感性，而不是仅给单次训练曲线或均值柱。该做法回应了强化学习结果高方差与小样本不确定性的报告问题（[Henderson et al., 2018](https://doi.org/10.1609/aaai.v32i1.11694)；[Agarwal et al., 2021](https://papers.nips.cc/paper/2021/hash/f514cec81cb148559cf475e7426eed5e-Abstract.html)）。
- **延迟是连续响应而非孤立情景。** 单图的 0–5 月曲线、`tau1`–`tau5` 平均和最坏延迟终点共同报告剂量响应、平均表现和尾部风险。

## 已提升、应作为次级终点的指标

| 维度 | 推荐报告 | 为什么 |
|---|---|---|
| 生态 | 生态流可靠性 + 年生态缺口体积 | 可靠性接近天花板时，缺口体积表达失败严重度；水资源系统的可靠性、恢复力、脆弱性（RRV）是经典的互补框架。[Hashimoto et al., 1982](https://doi.org/10.1029/WR018i001p00014) |
| 灌溉/粮食代理 | 灌溉需水满足率 + 年灌溉缺水量，并分宁夏/河套 | 当前数据反映供水服务，不含作物产量响应，不能称为粮食安全或产量。 |
| 能源 | 总能源需求满足率 + 年外购电量 | 分别描述服务水平和外部能源依赖；没有可追溯排放因子时，不应外推为碳减排。 |
| WEF 权衡 | 既定权重的成本贡献分解 + 固定策略权重重评分 | WEF 水库研究强调跨部门风险与权衡，而不是仅报告一个聚合值。[Qiu et al., 2021](https://doi.org/10.1016/j.jclepro.2020.124239) |
| 约束机制 | 原始–执行动作距离 + reserve-guard 限制释放量 | 投影频率、零安全违规和 100% 年末库容目标是确定性监督器的结果，应作为可行性审计。 |

## 不应作为主要算法优势的现有指标

- 终端库容达标、零安全违规、零库容回落、投影发生率：全部策略均被硬投影器强制满足。
- 水电量：当前情景几乎不随延迟变化，不应包装为 GNN 优势。
- `irrigation_satisfaction_ratio`：已重命名为 `irrigation_satisfaction_ratio_pct`，以避免把供水比例误作作物产量或食物安全。

## 用现有数据已经完成的新分析

1. **探索性最坏统一延迟风险：** 对每个 method × seed × 年度强迫序列先在 `tau1`–`tau5` 中取最大成本；它保留尾部风险，而非以平均值掩盖最坏延迟。
2. **部门贡献分解：** 将加权主终点拆为生态、加权能源、灌溉和年末库容贡献；其用途是解释主终点，不能替代多目标重新优化。
3. **固定策略偏好敏感性：** 能源权重 0.10–2.00、灌溉权重 0.50–2.00 的网格重新计分。动作和网络均未改变，因此不能写成“不同权重训练后仍最优”。
4. **区域服务审计：** 宁夏/河套分开报告，避免被全流域平均掩盖。
5. **配对假设敏感性：** 对相同数值种子是否构成严格跨架构配对保持保守；表 S3 给出不配对的种子标签置换结果。

## 投稿前仍需补齐的关键缺口

1. **因果可行性监督。** 当前年末库容 guard 使用剩余年度实际外源强迫序列。应改为所有方法可获得的预报/气候统计规则后重新训练，或将结论严格限定为“外部完美预见监督下的受约束模拟”。
2. **架构归因。** PPO 与 GNN-PPO 参数量不同；需补参数匹配的 MLP 或图边消融，才能把差异归因于图结构本身。
3. **外部泛化。** 2019–2021 含重复气候型输入，不能称为独立真实水文年。需要独立来水、干热/极端情景或经校准观测资料。
4. **失效序列。** 若补充新的非饱和情景，可加入 RRV、最长连续失效月数、CVaR_0.80（10 个种子时最差两个种子的均值）及延迟损失 AUC；当前生态失败过少，恢复力指标信息量有限。
